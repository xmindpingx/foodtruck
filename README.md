# El Otro Lado — Food Truck Launch Playbook

1990 GMC Step-Van · Mesa, Arizona · Maricopa County

This repository contains everything needed to get the food truck permitted, equipped, and operational — built for cost-effectiveness at every step.

## What's in here

| File | What it covers |
|------|----------------|
| `playbook.html` | Full interactive playbook — open in any browser |
| `docs/repairs.md` | Photo-based repair list sorted by inspection priority |
| `docs/permits.md` | Step-by-step permit roadmap with official fees |
| `docs/templates.md` | Fill-in communication templates (county, city, fire, commissary) |
| `docs/commissary.md` | Commissary options in the Mesa / East Valley area |
| `docs/grants.md` | Grants and financial assistance sources |
| `docs/equipment.md` | Complete equipment and supplies buy list |
| `docs/layout.md` | Station layout diagram and food safety rules |

## Quick start

1. Fix everything marked **MUST FIX** in `docs/repairs.md` before any inspection
2. Follow the permit steps in `docs/permits.md` in order — county before city
3. Use the templates in `docs/templates.md` for all official communication
4. Sign a commissary agreement (`docs/commissary.md`) before submitting county paperwork

## Minimum permit cost

| Item | Fee |
|------|-----|
| AZ LLC (ACC) | $50 |
| AZ TPT License | $12 |
| Food Handler Cards (×2) | ~$40 |
| ServSafe Manager Exam | $15–36 |
| Maricopa County Plan Review + Permit | $165 |
| Mesa Mobile Food Vendor License | $50 |
| **Total** | **~$332–353** |

## Menu

Authentic Hispanic street food: burritos, tacos, tostadas, chorizo and eggs — cooked to order on vehicle.
